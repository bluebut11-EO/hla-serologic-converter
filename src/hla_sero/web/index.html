Any layout works: a block copied from Excel, a report line, or a list. Two-field, full alleles, G/P groups, XX codes and ambiguity strings (B*15:01/15:03) are understood.

What the statuses mean
  • mapped serologically characterised (WMDA unambiguous or possible)
  • assumed no characterised serology; WMDA value assumed from the allele name — verify
  • ambiguous the alleles covered by this typing map to different antigens
  • null not expressed (N allele)
  • no-equivalent WMDA lists no serological antigen
  • not-found / unsupported not in this IMGT/HLA release, or an NMDP MAC code
Runs on this computer only — pasted typing never leaves it. Data: IPD-IMGT/HLA WMDA files (github.com/ANHIG/IMGTHLA). A tool for checking typing data; results need review before clinical use.
